## 🎯 Overview

**Enscape** is a real-time rendering, visualization, and virtual reality plugin for the AEC (Architecture, Engineering, Construction) industry. Unlike traditional renderers that require exporting models and waiting minutes for results, Enscape runs **directly inside your CAD/BIM software** — Revit, SketchUp, Rhino, Archicad, and Vectorworks — showing photorealistic results the moment you make a change .

Since merging with **Chaos** (makers of V-Ray), Enscape has become part of a unified ecosystem with **AI-powered design tools**, **cloud collaboration**, and **thousands of render-ready assets** .

### 🧩 What Makes Enscape Different

| Feature | Benefit |
|---------|---------|
| ⚡ **Real-Time** | No waiting for renders |
| 🔗 **Live Link** | Edits update instantly |
| 🎮 **GPU-Based** | Fast, responsive |
| 🥽 **VR Ready** | Walk through designs |
| 📦 **Asset Library** | 6,700–18,500+ models |
| 🤖 **AI Integration** | Veras, AI Enhancer |
| ☁️ **Cloud Collaboration** | Share with teams |

## 🖥️ System Requirements

### 🔹 Minimum

```
✅ OS: Windows 10 or higher (Windows 11 supported)
✅ GPU: Dedicated with 4GB VRAM, Vulkan 1.1+
       NVIDIA GTX 10 / Quadro P series+
       AMD RX 5000 series+
       Intel Arc A310
✅ CAD: Revit 2023+, SketchUp 2024+, Rhino 7+, Archicad 27+
✅ RAM: Matches your CAD requirements
✅ Internet: Stable (cable recommended for Asset Library)
```

### 🔸 Recommended

```
⭐ GPU: NVIDIA RTX 3070 Ti or AMD RX 6800
⭐ VRAM: 8GB+
⭐ CPU: Good multi-core (faster loading)
⭐ Dual monitors (Enscape optimized for it)
⭐ Direct cable internet connection
```

### 🥽 VR Requirements

```
✅ GPU: NVIDIA RTX 4070 Ti or AMD RX 7900 XT
✅ VRAM: 12GB
✅ Headset: Meta Quest 3 or HTC Vive Pro 2
```

> **⚠️ Important:** Enscape requires **dedicated VRAM**. Intel Integrated Graphics (shared VRAM) is not supported for rendering .

## ⚙️ Installation Workflow

### 🪜 Stage 1 — Access the Instructions

Open the official download portal from the button above.

### 🪜 Stage 2 — Check Compatibility

Confirm your CAD version is supported (see table above).

### 🪜 Stage 3 — Run the Installer

The Enscape installer **automatically detects** all installed CAD applications and installs the plugin for each. You can choose specific CADs during setup .

### 🪜 Stage 4 — Sign In with Chaos Account

When prompted, sign in with your Chaos account. Your license activates immediately .

### 🪜 Stage 5 — Verify Installation

Open your CAD software. You should see an **Enscape panel** or ribbon tab.

### 🪜 Stage 6 — Start Your First Render

Click **Start Enscape** — the rendering window opens alongside your CAD view .

### 🪜 Stage 7 — Explore the Asset Library

Browse **6,700–18,500+ render-ready assets** depending on your plan .

### 🪜 Stage 8 — Save and Share

Export stills, panoramas, or web standalones for clients.

## 🔄 Floating Licenses

### 🪜 Cloud-Based (Distributed Teams)

1. Admin logs into **my.chaos.com** → Organization
2. Invites users to the organization
3. Enables **Floating license sharing**
4. Users install Enscape and sign in 

### 🪜 Local Network (Small Teams)

1. Install Enscape on first machine
2. Sign in with license owner credentials
3. On subsequent installs, select **Advanced** and enter the first machine's IP address 

### 🪜 Larger Teams (10+)

Install a **Chaos License Server** on a central machine. Users point Enscape to the server IP .

## 💬 FAQ

**Is Enscape free?**
14-day trial, then paid subscription.

**Does it work on Mac?**
Windows only (Mac beta discontinued).

**Can I use it with Revit LT?**
No — Autodesk restricts plugins to full Revit .

**Do I need a powerful GPU?**
Yes — dedicated GPU with 4GB+ VRAM required.

**What's the difference between Solo and Premium?**
More assets, AI credits, and collaboration features.

**Can my team share a license?**
Yes — floating licenses support sharing.

**Does it render offline?**
Yes — assets load from local cache after initial download.

**How long does installation take?**
5–10 minutes typically.

**Can I install for multiple CAD apps?**
Yes — installer handles all detected CADs.

**Is VR supported?**
Yes — with compatible headset and GPU.
